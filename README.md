# Cetak Sertifikat ASAD

Aplikasi panitia Pengurus Kabupaten **Persinas ASAD Kutai Timur** untuk mengelola peserta kejuaraan (KEJURKAB, Pasanggiri, dan lainnya) serta mencetak sertifikat massal ke PDF.

- Frontend: HTML/CSS/JS murni di GitHub Pages
- Backend: Google Apps Script (REST API JSON) + Google Sheets
- Akses dilindungi PIN panitia

Konfigurasi satu-satunya: `js/config.js` → `GAS_URL`.
Langkah lengkap ada di **PANDUAN-INSTALASI.md**.
